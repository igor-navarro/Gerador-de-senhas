# Gerador de Senhas
 
Gerador de senhas seguras desenvolvido em Java, com opções de customização.
 
## Funcionalidades
 
- Geração de senhas com tamanho customizável
- Opção de incluir letras maiúsculas, minúsculas, números e símbolos
- Interface via linha de comando (CLI)
## Tecnologias
 
- Java
## Como usar
 
1. Clone o repositório:
```bash
   git clone https://github.com/igor-navarro/Gerador-de-senhas.git
   cd Gerador-de-senhas
```
2. Compile e execute a aplicação (ajuste conforme seu setup — Maven, Gradle ou `javac` direto).
3. Informe o tamanho desejado da senha e quais tipos de caracteres incluir.
